GTA VI COUNTDOWN WIDGET
=======================

الموعد المعتمد:
18 نوفمبر 2026، الساعة 4:00 عصرًا بتوقيت اليمن.
يعادل 19 نوفمبر 2026، الساعة 12:00 منتصف الليل في سيدني.

محتويات المشروع:
- Widget أصلي للشاشة الرئيسية.
- تحديث دوري تقريبي كل دقيقة، وقد يؤخر Android التحديثات لتوفير البطارية.
- عند الوصول للصفر يعرض IS OUT NOW.
- الضغط على الويدجت يفتح شاشة فيها عدّاد بالثواني.

مهم:
هذا مشروع مصدر Android وليس APK جاهزًا للتثبيت.
يلزم فتحه في Android Studio أو بيئة بناء Android متوافقة ثم بناء APK.
Acode وحده محرر نصوص ولا يبني تطبيقات Android أصلية.

بناء APK تلقائيًا عبر GitHub Actions:
1) أنشئ مستودع GitHub جديدًا وارفع محتويات هذا المشروع إليه.
2) افتح تبويب Actions في المستودع.
3) اختر Build GTA VI Countdown APK ثم Run workflow.
4) بعد انتهاء البناء، افتح نتيجة التشغيل (workflow run).
5) من Artifacts نزّل GTA-VI-Countdown-APK.zip، ثم استخرج app-debug.apk وثبّته على هاتفك.

يحتاج هذا المسار إلى حساب GitHub واتصال إنترنت. ملف APK الناتج نسخة Debug للتجربة.
